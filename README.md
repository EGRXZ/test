# FoldProfi — сайт сервиса ремонта Flip & Fold

Редизайн foldprofi.ru в дизайн-системе Umbrel (чёрный холст, Inter, персиковый и фиолетовый акценты)
с живыми 3D-сценами на Three.js. Чистый статический сайт: без сборки и зависимостей.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Нужен любой статический сервер (ES-модули не работают с `file://`). Подходит для GitHub Pages, Netlify, Vercel и любого хостинга.

## Структура

| Файл | Что внутри |
|------|-----------|
| `index.html` | Разметка и весь контент |
| `assets/css/tokens.css` | Токены дизайн-системы (цвета, типографика, радиусы, тени) |
| `assets/css/style.css` | Раскладка и компоненты |
| `assets/js/main.js` | Сцены и анимации на скролле |
| `assets/js/devices.js` | Процедурные 3D-модели: Fold, Flip, смартфон, часы, телефон в разборе |
| `assets/js/textures.js` | Содержимое экранов, нарисованное в canvas |
| `assets/js/stage.js` | Рендерер: отдельный canvas на сцену, рисует только видимое |
| `vendor/three/` | Three.js r170 (лежит локально, CDN не нужен) |

## 3D-сцены

- **Hero**: сложенный Fold на скролле делает оборот, раскрывается и показывает внутренний экран; реагирует на курсор.
- **Услуги**: смартфон, Flip, который сам открывается и закрывается, и часы. Модели можно крутить мышью или пальцем.
- **Неисправности**: Fold в разборе. При наведении на неисправность подсвечивается нужная деталь.
- **Плёнка**: старая плёнка отклеивается с уголка, новая ложится на её место.

`prefers-reduced-motion` отключает фоновые анимации. Без WebGL сайт работает как обычная статическая страница.
